# Tarea_M13_CD_robertscience – Proyecto 016

## Análisis de modelos de negocio con Ciencia de Datos

Este proyecto forma parte de mi portafolio de Ciencia de Datos aplicado a análisis empresarial.

En este trabajo desarrollé una plantilla reutilizable para analizar modelos de negocio mediante visualización, simulación y estructuración de información estratégica.

---

## Empresas analizadas

En este ciclo de trabajo desarrollé tres proyectos independientes:

- Vans “Off The Wall”
- Roxy
- Billabong

Cada empresa fue analizada utilizando la misma arquitectura base, modificando únicamente la identidad de marca, el contenido estratégico y los escenarios de proyección.

---

## Objetivo del proyecto

Mi objetivo fue construir una plantilla escalable que me permitiera:

- Analizar modelos de negocio con Business Model Canvas
- Generar activos visuales automatizados con Python
- Simular proyecciones de demanda
- Estandarizar documentación ejecutiva para exportación a PDF

---

## Arquitectura

El proyecto está estructurado como un sistema reutilizable basado en:

- Scripts en Python para generación de visualizaciones
- Business Model Canvas generado programáticamente
- Gráficas de proyección de demanda
- Documentación ejecutiva en Markdown exportable

---

## Resultados

A través de este sistema logré:

- Estandarizar el análisis de empresas bajo una misma metodología
- Automatizar la generación de activos visuales
- Crear entregables listos para presentación profesional
- Reutilizar el mismo pipeline para múltiples industrias

---

## Archivos principales

- `Tarea_M13_CD_robertscience.py` → generación de canvas y gráficas
- `canvas.png` → Business Model Canvas
- `grafica.png` → proyección de demanda
- `Tarea_M13_CD_robertscience.md` → reporte ejecutivo

---

## Conclusión

Este proyecto consolida mi capacidad para construir soluciones analíticas reutilizables aplicadas a negocio.

No se trata solo de visualización de datos, sino de un flujo completo que transforma información en decisiones estratégicas mediante Ciencia de Datos.
