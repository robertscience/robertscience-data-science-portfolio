# 📌 Descripción del Proyecto

Desarrollé este proyecto con el objetivo de construir una solución completa de Business Intelligence enfocada en el análisis financiero utilizando Power BI Desktop.

La solución fue diseñada para una empresa fintech ficticia denominada **RobertsX Finance**, creando un escenario empresarial compuesto por clientes, productos financieros, operaciones digitales e indicadores estratégicos.

Durante el desarrollo construí un flujo completo de generación, exploración y visualización de información.

Inicialmente desarrollé un generador de datos financieros utilizando Python, creando datasets estructurados para representar una plataforma financiera digital.

Posteriormente realicé una etapa de exploración y validación mediante un notebook analítico, para finalmente integrar la información dentro de Power BI y construir un dashboard interactivo.

---

# 🎯 Objetivo

El objetivo principal fue desarrollar una solución analítica capaz de transformar información financiera en indicadores útiles para la toma de decisiones.

Los principales objetivos fueron:

* Generar información financiera estructurada.
* Validar calidad y consistencia de datos.
* Construir un modelo analítico.
* Crear indicadores financieros mediante DAX.
* Diseñar visualizaciones interactivas.
* Representar información empresarial mediante Business Intelligence.

# 📂 Generación de Datos

Desarrollé el archivo:

`generate_fintech_data.py`

para crear automáticamente información financiera estructurada.

El proceso genera:

* Clientes.
* Productos financieros.
* Países.
* Transacciones.
* Indicadores económicos derivados.

Los archivos CSV generados durante este proceso no fueron incluidos dentro del repositorio debido a su tamaño.

La lógica completa de generación permanece disponible mediante el script principal, permitiendo reproducir nuevamente la información cuando sea necesario.

---

# 📓 Notebook de Exploración

El archivo:

`fintech_data.ipynb`

fue desarrollado como espacio de análisis y validación inicial.

Dentro del notebook realicé:

* Carga de datasets generados.
* Revisión de estructura.
* Validación de valores faltantes.
* Análisis de duplicados.
* Cálculo de métricas iniciales.
* Exploración de comportamiento financiero.

Este proceso permitió verificar la calidad de la información antes de utilizarla dentro del modelo desarrollado en Power BI.
