# Tarea M8 – Trabajo con Tablas en SQL Server (AdventureWorks2022)

## 📌 Descripción del proyecto

En este proyecto correspondiente al Módulo 8, desarrollé un ejercicio práctico en SQL Server utilizando la base de datos AdventureWorks2022.

Mi objetivo fue diseñar, poblar y modificar una tabla relacional simulando un sistema de órdenes de venta empresarial, aplicando operaciones fundamentales de administración de datos en un entorno SQL Server.

Este proyecto forma parte de mi portafolio de análisis de datos enfocado en prácticas reales de modelado y manipulación de bases de datos relacionales.

---

## 🛠️ Tecnologías utilizadas

- Microsoft SQL Server  
- Transact-SQL (T-SQL)  
- SQL Server Management Studio (SSMS)  
- Base de datos AdventureWorks2022  

---

## 🚀 Desarrollo del proyecto

Durante el desarrollo del proyecto realicé las siguientes actividades:

### 🔹 Creación de estructura de datos

Creé la tabla `dbo.Ventas` con campos orientados a la gestión de órdenes de venta, incluyendo información del cliente, fechas, estatus, método de pago y montos.

---

### 🔹 Inserción de datos

Inserté registros de ejemplo simulando diferentes estados de órdenes:

- Completadas  
- En proceso  
- Pendientes  
- Canceladas  

Esto me permitió trabajar con escenarios reales de análisis operativo.

---

### 🔹 Validación de información

Verifiqué la correcta inserción de los datos mediante consultas SELECT, asegurando la integridad de la información almacenada.

---

### 🔹 Modificación de estructura

Renombré la tabla de `Ventas` a `Ordenes` utilizando `sp_rename`, simulando un ajuste típico en entornos productivos donde los modelos de datos evolucionan.

---

## 🧠 Conocimientos aplicados

- Creación de tablas en SQL Server  
- Tipos de datos relacionales  
- Inserción de registros con INSERT INTO  
- Manejo de valores NULL  
- Consultas SELECT para validación  
- Administración de objetos en SQL Server  
- Renombrado de tablas con sp_rename
