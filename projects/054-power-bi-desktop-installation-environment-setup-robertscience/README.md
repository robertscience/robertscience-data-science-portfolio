# RobertScience Data Analytics Consulting

## Descripción del Proyecto

En este proyecto documenté el proceso completo de instalación y configuración inicial de **Power BI Desktop** dentro de un entorno Windows, preparando la herramienta para futuros procesos de análisis de datos, modelado y construcción de visualizaciones interactivas.

El objetivo principal fue establecer un ambiente funcional de trabajo para desarrollar soluciones orientadas a **Business Intelligence**, permitiendo utilizar Power BI como herramienta principal para transformación de datos, creación de modelos analíticos y generación de reportes ejecutivos.

Durante la instalación se presentó un inconveniente con el instalador tradicional de Power BI Desktop, por lo que realicé un diagnóstico del problema y utilicé una alternativa mediante **Microsoft Store**, logrando una instalación estable y completamente funcional.

Este proyecto representa una etapa fundamental dentro del flujo profesional de Data Analytics, donde la correcta configuración del entorno tecnológico es necesaria para garantizar procesos eficientes de análisis y visualización de información.

1. Evaluación Inicial del Entorno

Antes de realizar la instalación revisé las condiciones del sistema operativo para asegurar la compatibilidad de la herramienta.

Esta etapa permitió identificar posibles restricciones relacionadas con el método tradicional de instalación.

2. Instalación de Power BI Desktop

Realicé el proceso inicial de instalación utilizando el instalador disponible.

Durante esta etapa se presentó un inconveniente técnico que impedía completar correctamente el procedimiento convencional.

3. Resolución del Problema de Instalación

Después de analizar el comportamiento del instalador, implementé una alternativa mediante Microsoft Store.

Inicio correcto de la aplicación.

Disponibilidad del entorno de trabajo.

Finalmente accedí a la información del sistema para comprobar la versión instalada de Power BI Desktop.
