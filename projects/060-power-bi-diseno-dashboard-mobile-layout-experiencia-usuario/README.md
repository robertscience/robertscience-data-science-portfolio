📊 Diseño de Dashboards y Mobile Layout en Power BI
📌 Descripción del Proyecto

En este proyecto desarrollé un dashboard avanzado utilizando Power BI, enfocado en mejorar la experiencia de usuario mediante personalización visual, navegación interactiva y adaptación para dispositivos móviles.

El objetivo principal fue transformar un reporte analítico funcional en una solución más profesional, intuitiva y preparada para diferentes escenarios de consumo de información. Para lograrlo trabajé en la configuración visual del dashboard, creación de menús interactivos, integración de botones de navegación y optimización del diseño para dispositivos móviles.

Este proyecto representa una etapa enfocada en la presentación profesional de información, donde además del análisis de datos se considera la importancia del diseño, la accesibilidad y la experiencia del usuario final.

🎯 Objetivos del Proyecto
Diseñar una interfaz visual profesional dentro de Power BI.
Implementar navegación interactiva entre páginas del reporte.
Crear un menú principal utilizando botones y acciones.
Personalizar la apariencia del dashboard mediante temas visuales.
Adaptar el reporte para dispositivos móviles mediante Mobile Layout.
Mejorar la organización y experiencia de navegación del usuario.

🔄 Desarrollo del Proyecto
1. Personalización Visual del Dashboard

Durante la primera etapa trabajé en la mejora visual del dashboard, aplicando configuraciones de diseño orientadas a crear una presentación más limpia y profesional.

Realicé ajustes relacionados con:

Organización de elementos visuales.
Distribución del espacio dentro del canvas.
Configuración de fondos personalizados.
Integración de títulos e imágenes.
Mejoras en jerarquía visual de indicadores.

El objetivo fue construir una interfaz donde la información pudiera interpretarse rápidamente y donde cada elemento tuviera una función clara dentro del análisis.

🧭 Construcción del Menú Interactivo

Como parte fundamental del proyecto desarrollé una página principal utilizada como centro de navegación del dashboard.

Para esta sección implementé:

Botones personalizados.
Acciones de navegación entre páginas.
Organización por módulos de análisis.
Elementos visuales orientados a mejorar la experiencia del usuario.

Este enfoque permitió crear una estructura similar a aplicaciones empresariales de Business Intelligence, donde el usuario puede desplazarse entre diferentes análisis de manera sencilla y ordenada.

📱 Adaptación Mobile Layout

Posteriormente realicé la adaptación del dashboard para dispositivos móviles utilizando la funcionalidad Mobile Layout de Power BI.

Durante este proceso reorganizé los elementos visuales considerando:

Distribución vertical del contenido.
Prioridad de indicadores principales.
Legibilidad en pantallas pequeñas.
Accesibilidad de filtros y gráficos.

Esta adaptación permitió mantener la funcionalidad del dashboard en diferentes dispositivos, asegurando una experiencia consistente tanto en escritorio como en móviles.
