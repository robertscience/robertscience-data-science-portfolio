# RobertScience Data Analytics Consulting

## Descripción del Proyecto

En este proyecto realicé un análisis estadístico completo enfocado en la exploración de distribuciones, identificación de patrones de correlación y la construcción de un modelo de regresión lineal simple.

A través de diferentes visualizaciones analicé la distribución de la altura de ciudadanos en una ciudad y estudié diversos patrones de relación entre variables. Finalmente, construí y evalué un modelo de regresión lineal que explica la relación entre dos variables con un coeficiente de determinación (R²) de 0.864.

Este tipo de análisis es fundamental en la etapa exploratoria de cualquier proyecto de Ciencia de Datos y representa una base sólida para la toma de decisiones basada en evidencia estadística.

---

## Objetivo Técnico

El objetivo principal fue aplicar técnicas de estadística descriptiva y modelado predictivo para comprender la distribución de variables y las relaciones existentes entre ellas.

Durante el desarrollo del proyecto busqué:

- Analizar la distribución de una variable continua mediante diagrama de caja.
- Identificar diferentes tipos de correlación a través de gráficos de dispersión.
- Construir un modelo de regresión lineal simple.
- Evaluar la calidad del modelo mediante el coeficiente de determinación (R²).
- Interpretar los resultados desde un enfoque práctico y visual.

---

## Datasets Utilizados

Se trabajó con conjuntos de datos simulados que representan:
- Altura de ciudadanos de una ciudad (variable continua).
- Diferentes pares de variables para el estudio de correlación.
- Un dataset bivariado para la aplicación de regresión lineal.

Los datos originales no se incluyen en el repositorio por ser de carácter académico y de tamaño reducido, pero el código permite su reproducción completa.
