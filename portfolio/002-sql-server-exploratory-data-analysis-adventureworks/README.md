# SQL Server Exploratory Data Analysis - AdventureWorks2022

## 📌 Descripción del proyecto

En este proyecto realicé un análisis exploratorio de datos sobre la base de datos AdventureWorks2022 en SQL Server.

El objetivo fue explorar las principales entidades del modelo de datos, validar la información disponible y ejecutar consultas SQL para comprender la estructura general del sistema.

---

## 🛠️ Tecnologías utilizadas

- Microsoft SQL Server
- Transact-SQL (T-SQL)
- SQL Server Management Studio (SSMS)
- Base de datos AdventureWorks2022

---

## 🚀 Desarrollo del proyecto

Durante este proyecto ejecuté consultas SQL para análisis exploratorio:

### Exploración de personas

Consulté la tabla `Person.Person` para analizar la información de personas registradas en la base de datos.

---

### Análisis de recursos humanos

Filtré empleados en `HumanResources.Employee` para identificar roles específicos como “Marketing Specialist”.

---

### Análisis de contratación

Ordené los empleados por fecha de contratación para observar tendencias de incorporación de talento.

---

### Análisis de productos

Realicé filtros en `Production.Product` para analizar productos dentro de rangos de precios específicos.
