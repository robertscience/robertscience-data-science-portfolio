# Tarea M7 – Análisis de Datos con SQL Server (AdventureWorks2022)

## 📌 Descripción del proyecto

En este proyecto correspondiente a la **Tarea M7**, realicé consultas SQL sobre la base de datos **AdventureWorks2022**, con el objetivo de practicar extracción, filtrado, ordenamiento y análisis exploratorio de datos en un entorno empresarial simulado.

El enfoque principal fue comprender cómo interactúan las entidades de la base de datos y cómo puedo obtener información útil a partir de consultas estructuradas en SQL.

---

## 🛠️ Tecnologías utilizadas

- Microsoft SQL Server  
- Transact-SQL (T-SQL)  
- SQL Server Management Studio (SSMS)  
- Base de datos AdventureWorks2022  

---

## 🚀 Desarrollo del proyecto

Durante el desarrollo del proyecto ejecuté las siguientes consultas:

### 🔹 Análisis de empleados

Realicé la extracción completa de registros desde `Person.Person` para llevar a cabo un análisis general de datos personales.

Filtré empleados con el puesto **Marketing Specialist**, lo que me permitió identificar roles específicos dentro de la organización.

Ordené a los empleados por fecha de contratación (`HireDate`) en orden descendente para analizar patrones de incorporación.

---

### 🔹 Análisis de productos

Consulté productos cuyo precio de lista se encuentra entre 20 y 100, con el objetivo de analizar un segmento específico del catálogo comercial.

---

## 🧠 Conocimientos aplicados

- SELECT para extracción de datos  
- WHERE para filtrado de registros  
- ORDER BY para ordenamiento  
- BETWEEN para rangos numéricos  
- Análisis exploratorio de datos en SQL Server  
- Consultas sobre bases de datos relacionales

Con este proyecto fortalecí mis habilidades de análisis de datos mediante SQL, comprendiendo cómo explorar información estructurada dentro de una base de datos empresarial.
