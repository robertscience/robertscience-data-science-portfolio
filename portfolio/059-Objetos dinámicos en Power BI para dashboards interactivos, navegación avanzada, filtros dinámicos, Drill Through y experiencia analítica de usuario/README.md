# Objetos Dinámicos e Interactividad en Dashboards Power BI

## Descripción del Proyecto

En este proyecto desarrollé mejoras avanzadas de interacción dentro de un dashboard construido en Power BI, incorporando objetos dinámicos, navegación entre páginas y herramientas de exploración de datos.

El objetivo principal fue transformar un reporte tradicional en una experiencia analítica más flexible e intuitiva, permitiendo al usuario interactuar con la información mediante filtros dinámicos, segmentadores y navegación contextual.

A partir del modelo de datos y visualizaciones desarrolladas en proyectos anteriores, implementé funcionalidades que permiten analizar diferentes escenarios de negocio de manera más eficiente.


---

# Objetivos del Proyecto

Los principales objetivos fueron:

- Implementar objetos dinámicos dentro de Power BI.
- Mejorar la interacción del usuario con el dashboard.
- Crear filtros temporales mediante segmentadores.
- Configurar navegación entre páginas del reporte.
- Aplicar funcionalidades Drill Through.
- Diseñar una experiencia analítica más cercana a entornos empresariales reales.

# Desarrollo del Proyecto

## Implementación de Segmentadores Dinámicos

Como primera etapa incorporé objetos interactivos dentro del dashboard para mejorar la exploración de información.

Se implementó un segmentador dinámico de fechas utilizando un control deslizante, permitiendo modificar el periodo de análisis y actualizar automáticamente las visualizaciones conectadas al modelo de datos.

Esta funcionalidad permitió:

- Analizar diferentes periodos históricos.
- Comparar comportamientos temporales.
- Actualizar gráficos dinámicamente.
- Facilitar la exploración de tendencias.


El segmentador fue integrado considerando tanto la funcionalidad como la distribución visual del reporte, manteniendo una interfaz organizada y profesional.


---

# Configuración de Navegación entre Páginas

Posteriormente desarrollé una estructura de navegación interna dentro del dashboard mediante páginas conectadas.

Esta configuración permitió crear una experiencia más organizada donde el usuario puede desplazarse entre diferentes niveles de análisis.

La navegación fue diseñada para:

- Separar análisis generales y detallados.
- Mejorar la experiencia del usuario.
- Facilitar el acceso a información específica.
- Mantener una estructura clara dentro del reporte.


---

# Implementación de Drill Through

Una de las funcionalidades principales implementadas fue Drill Through, herramienta que permite profundizar en la información partiendo desde un elemento seleccionado dentro del dashboard principal.

Mediante esta funcionalidad fue posible crear análisis detallados sobre elementos específicos como:

- Productos.
- Países.
- Tiendas.
- Categorías.


El usuario puede seleccionar un elemento dentro del reporte principal y acceder automáticamente a una página especializada con información más detallada.


---

# Botones y Experiencia de Usuario

Para complementar la navegación agregué botones de retorno que permiten regresar fácilmente a la página principal del dashboard.

Esta implementación mejora la experiencia de navegación y permite construir un flujo similar al utilizado en soluciones profesionales de Business Intelligence.

La organización de los elementos visuales fue diseñada considerando:

- Facilidad de uso.
- Claridad de navegación.
- Consistencia visual.
- Acceso rápido a información relevante.


---

# Resultados Obtenidos

Como resultado final desarrollé un dashboard dinámico e interactivo capaz de adaptarse a diferentes necesidades de análisis.

La solución permite:

- Explorar información mediante filtros dinámicos.
- Analizar periodos específicos.
- Navegar entre diferentes niveles de detalle.
- Realizar análisis profundos mediante Drill Through.
- Mejorar la interacción con los datos.
