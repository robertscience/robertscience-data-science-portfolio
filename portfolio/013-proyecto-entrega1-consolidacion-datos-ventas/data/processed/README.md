# Processed Data

Esta carpeta está destinada a almacenar los datasets generados después de aplicar procesos de limpieza, transformación e integración.

Durante esta primera etapa del proyecto se realizó la preparación inicial de las fuentes originales.

Los resultados procesados pueden ser utilizados posteriormente para:

- Análisis exploratorio.
- Construcción de indicadores.
- Visualización de información.
- Desarrollo de modelos analíticos.

Los archivos generados no se incluyen dentro del repositorio cuando representan volúmenes elevados de información.
