# TextToSpeech Studio - Conversor de Texto a Audio con Python

## 📌 Descripción del proyecto

En este proyecto desarrollé una aplicación de conversión de texto a voz utilizando Python, creando una herramienta capaz de transformar contenido escrito en archivos de audio en formato MP3.

Mi objetivo fue construir una solución sencilla y funcional que permita introducir un texto, procesarlo mediante un motor de síntesis de voz y generar un archivo de audio reproducible, aplicando conceptos de automatización, procesamiento de información y desarrollo de herramientas digitales.

El proyecto representa una primera versión funcional de una aplicación de texto a voz, con una arquitectura preparada para futuras mejoras como interfaz avanzada, administración de archivos, selección de voces y procesamiento por lotes.

---

## 🎯 Objetivo del proyecto

Crear una herramienta que permita convertir texto escrito en audio de manera automática, facilitando la generación de contenido sonoro para diferentes usos:

- Lectura automatizada de documentos.
- Creación de material educativo.
- Generación de narraciones.
- Accesibilidad digital.
- Automatización de contenidos multimedia.

---

## 🛠️ Tecnologías utilizadas

- Python
- Google Text-to-Speech (gTTS)
- HTML5
- CSS3
- JavaScript
- Generación de archivos MP3

---

## ⚙️ Funcionamiento del sistema

El flujo principal de la aplicación es:

1. El usuario introduce un texto.
2. El sistema procesa la información recibida.
3. Python envía el contenido al motor de conversión de voz.
4. Se genera un archivo de audio en formato MP3.
5. El usuario puede reproducir el resultado generado.

---

## 🧩 Componentes del proyecto

### Backend - Python

Desarrollé el módulo principal encargado de:

- Procesar el texto recibido.
- Ejecutar la conversión mediante síntesis de voz.
- Generar archivos MP3 automáticamente.
- Controlar el flujo de creación del audio.

---

### Interfaz Web

Creé una interfaz inicial utilizando tecnologías web básicas para permitir una interacción más sencilla con la herramienta.

La interfaz permite:

- Introducir texto.
- Ejecutar la conversión.
- Preparar una experiencia de usuario más accesible para futuras versiones.
