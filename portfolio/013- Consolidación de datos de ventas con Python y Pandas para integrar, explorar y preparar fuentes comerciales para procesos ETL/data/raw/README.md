# Raw Data

Esta carpeta representa la capa de datos originales utilizada durante el desarrollo del proyecto.

Los archivos fuente fueron utilizados únicamente como entrada para los procesos de carga, exploración y validación inicial.

## Fuentes utilizadas

- DIM_CALENDAR
- DIM_CATEGORY
- DIM_PRODUCT
- DIM_SEGMENT
- FACT_SALES

## Consideraciones

Los archivos originales no forman parte del repositorio debido a su tamaño y con el objetivo de mantener una estructura ligera y eficiente para control de versiones.

La información documentada en esta sección permite conocer la composición del origen de datos utilizado durante el desarrollo.

## Flujo aplicado

1. Carga de fuentes.
2. Revisión estructural.
3. Validación de calidad.
4. Preparación para procesos ETL posteriores.
