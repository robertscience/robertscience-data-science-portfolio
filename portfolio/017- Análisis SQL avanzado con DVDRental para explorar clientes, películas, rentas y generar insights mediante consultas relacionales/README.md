# Avance de Proyecto 4 – Análisis SQL sobre DVDRental

## Proyecto 017 – Ciencia de Datos / SQL Avanzado

Este proyecto forma parte de mi portafolio de análisis de datos, donde aplico consultas SQL sobre la base de datos DVDRental para extraer información estratégica relacionada con clientes, películas, rentas y desempeño operativo.

---

## Objetivo del proyecto

En este proyecto realicé un análisis estructurado utilizando SQL con el objetivo de:

- Explorar la estructura de la base de datos DVDRental
- Aplicar consultas de filtrado, agregación y joins
- Identificar patrones de comportamiento en clientes y rentas
- Evaluar desempeño de películas y tiendas
- Generar insights a partir de datos relacionales

---

## Base de datos utilizada

Se utilizó la base de datos **DVDRental**, que contiene información sobre:

- Actores
- Películas
- Clientes
- Rentas
- Inventario
- Pagos
- Tiendas

---

## Consultas realizadas

Durante el desarrollo del análisis implementé consultas SQL como:

- Selección básica de actores
- Concatenación de nombres completos
- Filtrado con LIKE
- Agrupaciones con GROUP BY
- Subconsultas para valores máximos
- Joins entre tablas relacionadas
- Análisis de rentas y clientes activos
- Identificación de películas más rentadas
- Detección de registros sin actividad

---

## Hallazgos principales

A partir del análisis identifiqué:

- Concentración de rentas en ciertas películas con alta demanda
- Existencia de clientes sin actividad de renta
- Películas sin registros de alquiler
- Diferencias de comportamiento entre tiendas
- Actores con alta participación en múltiples producciones
